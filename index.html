How to connect multiple devices on GitHub Pages:
To link your phone, tablet, and laptop on your published GitHub Pages site, make sure all devices use the same **Classroom Key**.

Current Class Key: Default

Click the key button at the top header on any device to enter a custom code (e.g., MATH-101). Any devices with the matching code will share the exact same student roster and scan logs!
